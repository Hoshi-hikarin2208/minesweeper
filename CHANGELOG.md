# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-06

### Added

- Beginner, Intermediate and Expert levels
- Safe first click, flagging, chording, mine counter, timer and win/lose states
- Best times saved per level
- Mouse, touch (long-press and Flag mode) and keyboard controls
- Light and dark themes
- Installable, offline-capable Progressive Web App
- Engine unit tests and a GitHub Actions workflow
